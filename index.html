學生實作：上傳自己的圖片

只要記住：放檔案 → Commit → Push。

  1. 開啟 GitHub Desktop，按 Show in Explorer。
  2. 在 Taiwan_Scenic_100_Images/images 找到要替換的照片，例如 001.jpg，用自己拍攝或有授權的新照片覆蓋。
  3. 回到 GitHub Desktop，在 Changes 確認有修改。
  4. 輸入 Summary，按 Commit to main。
  5. 按 Push origin，等待網站更新。
