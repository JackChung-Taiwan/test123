# 臺灣景點 100 張圖卡 — GitHub Desktop 批次上傳練習

本包包含 `images/001.jpg` 到 `images/100.jpg`，共 100 張 JPG。每張圖片已控制在 100–200 KiB 之間，並附上 `attractions.csv` 對照表。

## 重要說明
這是專為「GitHub Desktop 批次管理與上傳檔案」課程製作的 **AI 生成景點主題示意圖**，不是景點現場拍攝照片，也不應作為旅遊實景介紹或實際路況／地貌依據。所有景點名稱與縣市為教學資料；圖像風格可能重複，也不保證精確呈現每個景點。

## 給學生：上傳到 GitHub
1. 到 https://desktop.github.com/ 安裝 GitHub Desktop，登入 GitHub。
2. 使用 File → New repository... 新增儲存庫 `taiwan-scenic-100`。
3. 在電腦的專案資料夾中新增 `images` 資料夾。
4. 複製本包 `images` 裡的 100 個 JPG 到專案 `images` 裡（請勿直接複製 ZIP 檔來代替解壓縮）。
5. 返回 GitHub Desktop，確認 Changes 中有 100 張圖片，輸入 Summary：`Add 100 Taiwan scenic cards`。
6. 點 Commit to main；若尚未發佈儲存庫，點 Publish repository（初次上傳）；如果已發佈，點 Push origin（後續更新）。
7. 在 GitHub 網頁查看 `images` 資料夾，應有 100 個 JPG。
